# Changelog

## 1.1.0

- Added Centrals such as El-Hadra and Karmouz.
- Added an admin-only Central management screen.
- Added active/inactive Central controls that preserve existing surveys.
- Added Central selection when creating a block survey.
- Added a shared Central filter for the map and survey list.
- Added Central details to markers, survey cards, and survey details.
- Strengthened Firestore rules so only users with `role: admin` can create or
  change Centrals.

## 1.0.0

- Initial GPS apartment-block survey application.
- Floor and apartment exceptions, block photos, Internet-box mounting marker,
  Firebase Authentication, Firestore, and Storage.
